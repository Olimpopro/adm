# Áreas comuns — galeria de fotos

Cada subpasta corresponde a um POI (ponto de interesse) marcado na planta.
Coloque imagens JPG/PNG/WebP dentro da pasta da área e elas aparecem
automaticamente no modal de galeria do site.

## Pastas

| ID            | Área                              |
| ------------- | --------------------------------- |
| `lazer/`      | Área de Lazer (clube central)     |
| `quadra-areia/` | Quadra de Areia Poliesportiva   |
| `piscina/`    | Piscina                           |
| `bar/`        | Bar da Piscina                    |
| `praca/`      | Praça Stela Pithon Moreira        |

## Recomendações

- **Tamanho:** 1600–2400px no lado maior, JPG qualidade 82–88
- **Formato:** paisagem (4:3 ou 16:9) renderiza melhor no modal
- **Ordem:** as fotos aparecem em ordem alfabética do nome — use prefixos
  numéricos para controlar (`01-hero.jpg`, `02-piscina.jpg` etc.)
